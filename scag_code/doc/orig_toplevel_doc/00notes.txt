Step 1:
last entry in input set up file is solar zenith.

at horizon.

directly overhead.

file.)

that you can submit to more nodes/tasks simulatneously.

and/or we have more memory to work with...)

to work with.  We will need to scope this.

Output are written to /fsca/Landsat8/ etc.

under that there are subdirs by tile and

full/ - no saturation
sat1/ - sat in band1 only
sat13/ - sat in bands 1 and 3 only

these are for various runs assuming different saturation.  If
bands 1, 2 and 3 area all saturated that's handled in a
post-processing IDL step.

So there are 4 possible runs.

At the same level as these full/sat1/sat13 directories are the
.img files that are combinations of output from the various runs.

script to run the processing there:

'xXYyyyymmddpPPPrRRR'

From web posting on reading .sli files:

To read .sli file in IDL, an .sli file is just a binary array
with spectra saved in rows (so it's the same format as a BIP
tile).  To read it, you'll need to know the number of spectra
(nspec), number of pts per spectrum (npts), the datatype (dt),
and whether or not there's an offset.  Assuming there's offset=0,
and the path to your library file is stored in the variable
sli_file, then this should work: sli = make_array(npts, nspec,
type=dt) openr, lun, sli_file, /get_lun readu, lun, sli free_lun,
lun If there's an offset, handle that with a point_lun in between
openr and readu.

To read/display an .sli file in ENVI:
- open ENVI new version
- File->Open (open the .sli file)
  - this will open the "Spectral Library Viewer" 
- To select all spectra for display on same plot:
  Import->Spectral Library...
  Choose the sli file to view  
  Select all items
  OK
  - expand arrow to right side
    - set title and yaxis title

2021-04-27

How to convert flat binary uint8 or uint16 array to geotiff?

Building conda env on summit for scag:

conda create -n scag gdal

it got gdal v

(latest version on web page is 3.2.2)

1) To convert flat binary image file to non-georef'd tiff:

convert -size 7591x7551 -depth 8 -define quantum:format=unsigned
gray:LC08_L2SP_042034_20130322_20200913_02_T1.snow.bin test.tif

2) Make it a geotiff:

proj4 string for UTM zone 11:
a_srs="+proj=utm +zone=11 +datum=WGS84 +units=m +no_defs +ellps=WGS84"

ul/lr projected coordinates of the image (corners of corner
cells, in meters), guess: "ulx uly lrx lry"
from:
SENSOR_PLATFORM,LINES,SAMPLES,SUN_ZENITH,MAP_PROJECTION,ZONE_NUMBER,ELLIPSOID,DATUM,GRID_CELL_SIZE_REFLECTIVE,CORNER_UL_PROJECTION_X_PRODUCT,CORNER_UL_PROJECTION_Y_PRODUCT,CORNER_LR_PROJECTION_X_PRODUCT,CORNER_LR_PROJECTION_Y_PRODUCT
"OLI,8",7551,7591,41.80901353,UTM,11,WGS84,WGS84,30,150300,4263600,378000,4037100

a_ullr=150300. 4263600. 378000. 4037100.  <--no quotes
a_nodata=255 (for uints)

gdal_translate -a_srs $a_srs -a_ullr $a_ullr -a_nodata 255 test.tif geotiff.tif
